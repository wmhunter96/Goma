# Sesame DevKit Carrier v1

Plug-in carrier board for a **30-pin ESP32 DevKit (DOIT DevKit V1 style, 1.0" / 25.4 mm between pin rows)**.
Replaces hand wiring: 3S battery in, onboard 5V/5A regulator, 8 servo headers, OLED header, battery voltage sense, spare I/O.

- Board: **80 × 42 mm**, 2 layers, 1.6 mm, all through-hole
- The DevKit lies along the board with its **USB port flush with the left edge**, so leave an opening in the body there for flashing
- Pin map matches the firmware's "Distro Board V1 / DevKit" settings, so no firmware pin changes are needed
- Generated by `build_board.py` (run with KiCad 10's bundled python). Edit the script, not the `.kicad_pcb`, then re-run it.
- `sesame-devkit-carrier.step` is the 3D model for designing the body around the board.

## Pin map

| Function | DevKit pin | Board |
|---|---|---|
| Servo L1 / L2 / L3 / L4 | D23 / D19 / TX2 (17) / D18 | S headers, labelled |
| Servo R1 / R2 / R3 / R4 | D15 / D2 / RX2 (16) / D4 | S headers, labelled |
| OLED SDA / SCL | D21 / D22 | J3 |
| Battery sense | D34 (GPIO34, ADC1) | via 100k/27k divider, after the switch |
| Spare I/O | D32 D33 D25 D26 D27 D14 D13, GND, 5V | J4, J5 (each pin directly above its DevKit pin) |
| 5V in | VIN | from U1 |

Servo headers are **S + −** from the DevKit outward: orange toward the DevKit, brown on the outer (−) pin, nearest the board edge.

## Before you power it

1. **Check your DevKit's printed labels** against the silkscreen: USB toward the left edge, D23 at the antenna end of the row nearest the servo headers.
2. **XT30 polarity:** the footprint puts **+ on the pad nearer the capacitor** (marked +). Confirm against the + and − markings on your battery's plug before soldering J6. The Pololu module has reverse-voltage protection, but check anyway.
3. With nothing plugged in, use continuity mode: 5V to GND, and battery + to GND, must **not** beep.
4. First power-up with the DevKit only, no servos. Measure 5V at the servo + pins before plugging servos in.

## Battery reading in firmware

`V_battery = V_GPIO34 × (100k + 27k) / 27k = V_GPIO34 × 4.70`

```cpp
float batteryVolts() {
  return analogReadMilliVolts(34) * 4.7037f / 1000.0f;   // 12.6 V full, ~10.5 V time to charge (3S)
}
```

## Notes

- No copper under the ESP32 antenna (keep-out zone at the DevKit's right end), to keep Wi-Fi range.
- The DevKit's own micro-USB is used for flashing; there's deliberately no second USB-serial chip on the carrier.
- There's no schematic file; `build_board.py` is the source of truth for every connection.
